---
title: Installation
description: Install the Khaos CLI via Homebrew, go install, a prebuilt release binary, Docker, or from source.
---

Khaos ships as a single static binary with no runtime dependencies. Docker is only required if you
want to use the bundled local Kafka cluster (`khaos run`); [`khaos simulate`](/docs/reference/cli#khaos-simulate-scenario)
against an external cluster needs nothing but the binary.

## go install

Requires Go.

<Terminal
  lines={[
    { type: "command", text: "go install github.com/aleksandarskrbic/khaos/cmd/khaos@latest" },
  ]}
/>

## Download a release binary

Prebuilt binaries for `linux`/`darwin`/`windows` on `amd64`/`arm64` are attached to every
[GitHub release](https://github.com/aleksandarskrbic/khaos/releases). Download the archive for
your platform, extract it, and put the `khaos` binary on your `PATH`.

## Docker

<Terminal
  lines={[
    {
      type: "command",
      text: "docker run --rm ghcr.io/aleksandarskrbic/khaos:latest simulate traffic/high-throughput --bootstrap-servers kafka:9092",
    },
  ]}
/>

Scenarios and the bundled compose files are embedded in the image, which runs as a non-root user on
a distroless base, and nothing else ships with it. Because Docker-in-Docker isn't supported, the
container image only supports `khaos simulate` against an external cluster, not `khaos run`'s
managed local cluster.

## From source

<Terminal
  lines={[
    { type: "command", text: "git clone https://github.com/aleksandarskrbic/khaos.git" },
    { type: "command", text: "cd khaos" },
    { type: "command", text: "go build -o khaos ./cmd/khaos" },
    { type: "command", text: "./khaos --help" },
  ]}
/>

## Homebrew

<Terminal
  lines={[
    { type: "command", text: "brew install khaos" },
  ]}
/>

`khaos` is in homebrew-core, built directly from Go source with no runtime dependencies.

## Verify

<Terminal
  lines={[
    { type: "command", text: "khaos --version" },
    { type: "command", text: "khaos --help" },
  ]}
/>
